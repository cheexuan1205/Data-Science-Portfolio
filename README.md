# Titanic Passenger Analysis: Anomaly Detection, Pattern Recognition, and Predictive Modeling
This repository demonstrates a complete data science workflow using the Titanic dataset, showcasing anomaly detection, pattern recognition, and predictive modeling techniques. The project highlights proficiency in Python, Pandas, NumPy, and Scikit-learn, along with SQL integration for data extraction and transformation.

Key Features:

Exploratory Data Analysis (EDA): Visualizations and summary statistics to uncover trends and patterns in passenger demographics and fares.

Anomaly Detection: Identification of unusual ticket fares using statistical rules and automated workflows.

Pattern Recognition: Analysis of survival patterns based on passenger class, gender, and other factors.

Predictive Modeling: Logistic Regression model to forecast passenger survival, demonstrating machine learning skills.

SQL Integration: Use of CTEs, joins, and aggregation via pd.read_sql() to extract and manipulate data efficiently.

Automation: Python-based workflows to flag outliers and generate actionable insights.

Portfolio-Ready: Designed to showcase skills in data cleaning, feature engineering, modeling, and workflow optimization.

Skills Highlighted:

Python (Pandas, NumPy, Scikit-learn)

SQL (CTEs, joins, aggregation)

Data Cleaning & Transformation

Outlier Detection & Anomaly Analysis

Predictive Analytics & Classification

Workflow Automation

Use Case:
This project simulates a real-world data science scenario where irregular behaviors, anomalies, and patterns in transaction-like data are identified, analyzed, and modeled, reflecting skills applicable to analytics, monitoring, and predictive modeling roles.
